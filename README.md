An appliance error message that tells the truth instead of hiding behind a code. The blender's blade is doing its job — spinning — while the contents sit there unmoved, which means whatever is inside the jar has, for the moment, won. It is funny because it is exactly what a stuck blender feels like: the machine is working, the food is not, and the jar has become the boss.

## Run

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), reads it back, and verifies it is byte-identical.
